<h3 align="center"> MIMO Antenna System For Radar at 8 GHz with Real-Time Fault Detection via Streamlit GUI </h3>
<p align="left"> 
  The MIMO antenna system is engineered to enhance radar performance by offering improved spatial diversity, 
  higher resolution, and better target detection capabilities. 
  Each antenna element is optimized for high gain, low mutual coupling, and consistent radiation patterns 
  to ensure reliable system behavior under dynamic operating conditions.
  A key innovation in this work is the incorporation of real-time fault detection, 
  which monitors parameters such as return loss (S11), isolation (S21), and gain variations across the antenna array. 
  Using Python and machine learning algorithms, the system analyzes incoming data to detect potential faults like element damage,
  misalignment, or feed line issues. The Streamlit GUI provides an intuitive platform for visualizing antenna parameters and fault diagnostics,
  enabling users to interactively assess system health and performance in real time. 
  This integration of hardware and software not only enhances radar reliability and maintenance 
  but also demonstrates the potential of intelligent antenna systems for future defense and aerospace applications.
  The proposed system offers a scalable and efficient solution for next-generation radar technologies.</p>
